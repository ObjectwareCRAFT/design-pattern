### Template Method

Create a `PizzaMaker` capable of handling multiple types of pizza.

**Examples:**

**How to make a Margherita:**
1. Prepare basic dough
2. Add tomato base
3. Add mozzarella cheese
4. Bake at 250°C for 5 minutes
5. Add basil
6. Pack in red box

**How to make a Cheesy:**
1. Prepare mozzarella dough
2. Add cream base
3. Add goat cheese, mozzarella, gruyere, and blue cheese
4. Bake at 260°C for 7 minutes
5. Add olives
6. Pack in white box
